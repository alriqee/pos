# POS Lite - Offline-First Point of Sale

POS Lite is a modern, lightweight, and offline-first Point of Sale application designed for small businesses. Built with **Electron**, **React**, and **Vite**, it provides a seamless desktop experience with the power of web technologies.

## 🚀 Features

- **Offline-First**: Works without an internet connection using local storage.
- **Bilingual Support**: Easily manage products in English and Arabic.
- **Automatic Translation**: Integrated Google Translate support for product names.
- **Invoice Management**: Generate, view, and print professional invoices.
- **Product Management**: Simple CRUD for products with Excel import/export.
- **Responsive Design**: Clean and modern UI built with Tailwind CSS.
- **Remote Lock**: Built-in security mechanism for remote application control.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Framework**: Electron
- **Bundler**: Vite
- **Database**: LowDB (JSON-based) for local storage.
- **Icons**: React Icons (Heroicons)

## 📦 Installation

To run this project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alriqee/pos.git
   cd pos
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
   The installer will be generated in the `release/` directory.
